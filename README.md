The ZIP contains the VL53L4CD driver and breakout bridge source, integration
instructions, board photos, and the breakout schematic. This repository hosts
the README and downloadable release packages; source files are included in
the ZIP rather than published separately.

**This is source code, not a precompiled firmware image.** The MCU-specific I2C
and delay hooks must be implemented for the target board before building and
flashing firmware. See the package README for integration details.
